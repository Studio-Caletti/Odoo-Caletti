# 🎨 Caletti Creative: Sistema de Gestión Creativa (SGC)

**Vertical estratégica para Despachos de Artes Gráficas, Agencias y Estudios Digitales.**

---

## 📄 Descripción
El **SGC** es el pilar de producción de Studio Caletti. Está diseñado para resolver el caos común en las agencias creativas: la falta de acuerdos claros y el exceso de revisiones no facturadas. Convierte a Odoo en un aliado de la rentabilidad creativa.

## 🚀 Funcionalidades Estratégicas
* **📘 Briefing Maestro:** Documento de directivas de diseño que actúa como contrato operativo. Define el tono, la audiencia y los objetivos antes de mover un solo píxel.
* **🔄 Versionamiento de Propuestas:** Control estricto de iteraciones (`v1`, `v2`, `v3`...). Cada cambio solicitado queda registrado, permitiendo auditar la evolución de la idea.
* **📦 Sub-tareas de Entregables:** Desglose técnico de piezas (Logos, Manuales, Videos, Social Media) con estados de aprobación independientes.
* **⚠️ Control de Rentabilidad:** Alertas automáticas cuando el cliente supera las rondas de cambios pactadas, permitiendo la gestión de costos adicionales.

## 🛠️ Detalles de Ingeniería
* **Modelos Propios:** `creative.brief`, `creative.deliverable`, `creative.team.member`.
* **Colaboración:** El **Chatter** está optimizado para la revisión de activos visuales y feedback directo del Director Creativo.
* **Integración:** Totalmente compatible con los módulos nativos de **Ventas y Facturación** de Odoo.
